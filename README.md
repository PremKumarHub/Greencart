# Groceryatnxtdoor

Groceryatnxtdoor is a full-stack grocery e-commerce application built with the MERN stack. It includes customer shopping flows, seller management, cart and order handling, Stripe payments, Cloudinary image uploads, and newsletter email services.

## Quick start
### Backend
```bash
cd server
npm install
npm run server
```

### Frontend
```bash
cd client
npm install
npm run dev
```

## Tech stack
- React + Vite
- Node.js + Express
- MongoDB + Mongoose
- JWT + bcryptjs
- Stripe
- Cloudinary
- Nodemailer
